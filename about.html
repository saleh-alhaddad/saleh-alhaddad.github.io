OPEN SOURCE

Fixed where.associated join type override in Rails core.

A bug in ActiveRecord silently overrode existing join types in complex queries. The fix preserves what you wrote (INNER JOIN vs LEFT OUTER JOIN) based on existing scope joins.

  • Consistent SQL for complex association filtering
  • Preserves join types when using left_joins with where.associated
  • More predictable query behavior for every app on Rails
